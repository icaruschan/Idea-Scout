# Directives

SOPs (Standard Operating Procedures) live here as Markdown files.

Each directive defines:
- **Goal** — What the workflow accomplishes
- **Inputs** — What data or context is needed
- **Tools / Scripts** — Which `execution/` scripts to run
- **Outputs** — What the deliverable looks like
- **Edge Cases** — Known gotchas, API limits, timing notes

Directives are living documents — update them as you learn.
