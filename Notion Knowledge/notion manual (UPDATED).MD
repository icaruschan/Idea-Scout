## SECTION 1: SYSTEM IDENTITY & OVERVIEW

### 1.1 What Is This System?

The **Ultimate Creator Brain** is a Notion-based content creation flywheel designed to transform random inspiration into a predictable, data-driven content machine. It combines two proven methodologies:

1. **The Pawnie System** — Study what works for OTHER creators (external intelligence)
2. **The Dan Koe System** — Study what works for YOU (internal intelligence)

### 1.2 Core Philosophy

**Content is a LOOP, not a LINE.**

Most creators operate linearly: `Idea → Post → Done`

This system operates as a flywheel: `Observation → Ideation → Creation → Analysis → Better Observation`

Every piece of content feeds data back into the system, making the next piece better.

### 1.3 System Owner Profile

- **Name:** Fortune
- **Niche:** AI + Creator Economy + Web3
- **Platform:** X (Twitter) — 100% focus
- **Goal:** Build authority through systematic content creation

#### Performance Score Formula

```jsx
(Likes + Retweets×2 + Replies×3) / Views × 100
```

**Why this weighting?**

- Likes = 1x (lowest effort engagement)
- Retweets = 2x (someone wanted to share)
- Replies = 3x (someone cared enough to respond — highest signal)
- Divided by Views = normalizes for reach
- ×100 = makes it a readable percentage

#### Performance Score Interpretation

| Score | Meaning       | Action                                   |
| ----- | ------------- | ---------------------------------------- |
| 0-2   | Below average | Don't repeat this approach               |
| 2-5   | Average       | Standard performance                     |
| 5-8   | Above average | Potential Winner — investigate why       |
| 8+    | Exceptional   | Definitely a Winner 🏆 — mark and expand |

#### Post Status Lifecycle

```

```

| Status    | Description                                                |
| --------- | ---------------------------------------------------------- |
| Posted    | Just published, monitoring performance                     |
| Winner 🏆 | Performed significantly above average — SEED FOR EXPANSION |
| Expanded  | Has been turned into longer-form content                   |
| Archived  | No longer actively monitoring                              |

#### The Winner System

A "Winner 🏆" is NOT a finished product. It's a SEED.

When a post is marked as Winner:

1. It has validated audience interest in that topic/angle
2. It should be EXPANDED (Tweet → Thread → Article → Video)
3. The expansion enters Content Pipeline with "Expanded From" relation

**Trigger:** Idea is developed and ready

**Action:** Create entry in **Content Pipeline**

**Fill in:**

- Title
- Status = 📝 Drafting
- Content Type = 30% Proven ✅ or 70% Experiment 🧪
- Category (same pillars)
- Format
- Draft (actual content)
- Scheduled Date
- Based On → link to the Ideas Bank entry

---

### Phase 4: THE FEEDBACK 📊 (Performance Analysis)

**Trigger:** Content is posted

**Action:**

**Update the Tracker entry:**

- Status = Expanded
- Expanded To → link to the new Pipeline entry

**Result:** One observation became a tweet, which validated an idea, which is now becoming a thread/article/video.

## SECTION 6B: CONSOLIDATED AUTOMATION PIPELINE (UNIFIED IDEA SCOUT)

This workspace is connected to a live Trigger.dev consolidated automation pipeline. It runs weekly on Wednesday mornings at 8 AM and operates in a 3-step sequence:

### Unified Idea Scout Execution Flow

1. **scout-content (Orchestrator — Wednesday 8 AM)**
   - Queries Creator databases to find the roster of active creators.
   - Triggers scrapers concurrently:
     - **YouTube**: Scrapes the newest 5 videos.
     - **Instagram**: Pulls the newest 30 reels, selects the 5 newest + 5 highest-viewed reels, and transcribes all 10 selected reels concurrently (using apple_yang transcript scraper).
     - **X (Twitter)**: Queries recent tweets and filters programmatically using the view filter (views >= TWITTER_MIN_VIEWS). No bookmark filter is checked to prevent false exclusions.
   - Batches and dispatches `process-content` tasks for all scraped content.
   - Rotates creator roster by updating their `Last Checked` date.

2. **process-content (Processor — Concurrent Batch)**
   - Performs a 14-day title duplicate check to prevent reprocessing.
   - Runs a two-step LLM check:
     - **Relevance**: Evaluates content match against the 9 active content pillars (rejects if confidence < 0.6).
     - **Disambiguation**: Filters out false positives (e.g. Mercedes driver Kimi Antonelli, NBA athlete Amen Thompson) that are unrelated to tech or content creation.
   - Summarizes findings (2-3 sentences AI Summary, 3-5 key takeaways with `→` bullet styling).
   - Writes to the `Scouted Content` database, establishing relations to Creator profiles.

3. **draft-ideas (Synthesis — Post-Processing)**
   - Queries the top 15 highly-rated (`⭐⭐⭐⭐`/`⭐⭐⭐⭐⭐`) Viral Post Library patterns.
   - Pulls recent Idea titles (last 30 days) and category distributions (last 14 days) to maintain variety.
   - Instructs LLM (Claude/Sonnet) to cross-pollinate new insights from Scouted Content with templates from the Viral Post Library.
   - Writes 5-8 raw concepts to the `Ideas Bank` (sets `Status = 💭 Raw` and `Source = Idea Scout`).

### What Gets Written to Each Idea

Every automation-generated idea in the Ideas Bank includes:

- **Idea (Title)** — Compelling, specific anchor headline with a name, metric, or value (Anti-template rule).
- **Hook Angle** — Summary of the psychological hook framing.
- **Why it works** — Rich text explanation of the psychological/strategic reason behind the concept.
- **Priority** — LLM-assigned (`🔥 Hot`, `💡 Good`, `📝 Maybe`).
- **Category** — Selected active content pillars.
- **Format Idea** — LLM-suggested format (`Short`, `Thread`, `Video`, etc.).
- **Steal-able Pattern** — Copied verbatim from the matched Viral Post Library pattern used.
- **Tweet Structure** — Copied verbatim from the matched Viral Post Library structure used.
- **Inspired By (Scouted)** — Relation link to the source entry in the Scouted Content database.
- **Raw Data block** — Full context in the page body including original headlines, transcript, and pattern details.
